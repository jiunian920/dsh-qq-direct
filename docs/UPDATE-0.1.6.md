# v0.1.6 更新说明

## 同一个主会话里的桌面回群

- 桌面先收到群消息索引。用 `qq_desktop_group_index` 查消息 ID 和原句，再由智能体用 `qq_desktop_draft` 提交自己写的正文与材料清单。材料可以是原群消息和明确批准的公开资料。文字通过核验后原样发送，回执返回正文、实际引用 ID 和发出消息的 ID。
- 桥再次核对目标群、原消息、发言人、会话绑定、有效期和材料。查看群正文后，当前回合的工具收窄到这条草稿路径。同轮桌面输入、已收取的桌面工具结果及近期 QQ 私聊会参与已知复制片段检查。该检查覆盖可识别的片段与常见路径和凭据特征。
- 同一主会话仍提供 QQ 私聊、群聊和桌面入口。已有文字、表情、语音、图片和文件回归通过。普通群发可自然接话，桌面文字草稿遇到其他人插话时自动引用原消息。点名只影响接话，群友点名无法取得命令、电脑文件或私人记忆工具权限。

## 主动观察、自主时间和用量

- 定时观察从上次检查取新群消息，每隔 20 到 50 分钟检查一次。桥优先挑同题材料，普通新话题也可交给智能体自行判断。即时活动与定时检查的计数分开，逐次日志按北京时间日期保存。
- 自主时间可用本机画图工具保存 SVG，也可在已配置相应安全网页工具的安装上阅读公开网页。该来源记为 `free`。发布包默认关闭自主时间，将 `directSession.automaticObservation.freePer24Hours` 设为 1 到 4 即可启用。
- 用量按回合记录。下一次启动会收录未结束回合最后一次成功写入的快照。默认估算 DeepSeek Flash 的峰谷费用。内置节假日到 2027 年，`--model` 或 `--rates` 可指定其他计价方式。中断回合显示已观测到的用量。

## 升级方式

1. 在一个空闲时段停下 QQ 桥并退出 DSH。备份现有本机配置和 `state/`。
2. 将对应源码更新到部署目录，在 `qq-bridge` 下运行 `npm ci` 和 `npm test`。使用 Node.js 22.13 或更新版本。
3. 保留原来的本机 `config.json`，按需合并示例里的新字段。DSH 插件与桥须一起更新，启动后核对两边仍指向当前主会话。
4. 如需引用公开记忆，使用随仓库的 `memory-app` 目录，或为桥与 DSH 设置一致的 `AI_MEMORY_ROOT`。公开库必须由使用者本机建立并明确批准资料。纯群聊材料就可以写文字草稿。

```sh
node qq-bridge/scripts/direct-turn-usage.mjs --last=50 --observation-stats --checks=2026-11-19
```

升级包内含源码、匿名示例和离线回归。安装者在本机提供 OneBot、DSH、QQ 配置，以及可选的 Python 记忆或语音服务。
